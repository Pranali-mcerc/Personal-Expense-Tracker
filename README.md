\# 💰 Personal Expense Tracker



A Python-based Personal Expense Tracker with an interactive dashboard for managing expenses, analyzing spending habits, and tracking monthly budgets.



\## 📊 Dashboard



An interactive dashboard built using Streamlit to visualize expenses, categories, monthly spending, and budget progress.



\## ✨ Features



\- Add, view and delete expenses

\- Expense categorization

\- Monthly spending analysis

\- Interactive charts and visualizations

\- Budget management and alerts

\- CSV data export

\- Expense reports

\- Filter transactions by date and category



\## 🛠️ Tech Stack



\- Python

\- Pandas

\- NumPy

\- Streamlit

\- Plotly

\- Matplotlib
